# Waleed Ali - Portfolio Website

A modern, responsive portfolio website showcasing my projects, technical expertise, and volunteering experiences. Built with Next.js 16, React 19, and Tailwind CSS.

## 🚀 Features

- **Project Showcase**: Interactive display of featured projects with video demonstrations
- **Technical Stack**: Comprehensive overview of technologies and tools I work with
- **Volunteering Section**: Gallery showcasing community service experiences in Costa Rica and Mexico
- **Responsive Design**: Fully responsive layout optimized for all devices
- **Dark Mode**: Built-in dark mode support for better viewing experience
- **Performance Optimized**: Fast loading times with Next.js Image optimization and code splitting

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) with App Router
- **UI Library**: React 19
- **Styling**: Tailwind CSS 4
- **Language**: TypeScript
- **Deployment**: Vercel (recommended)

## 🏃 Getting Started

### Prerequisites

- Node.js 18+ 
- npm, yarn, pnpm, or bun

### Installation

1. Clone the repository:
```bash
git clone https://github.com/waleed399/waleed-portfolio.git
cd waleed-portfolio
```

2. Install dependencies:
```bash
npm install
# or
yarn install
# or
pnpm install
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

## 🏗️ Build for Production

```bash
npm run build
npm start
```

This creates an optimized production build of the application.
